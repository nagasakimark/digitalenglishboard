# Decorations Folder

This folder contains decoration images used on the cork board.

## Usage

When you upload a decoration image through the editor:
1. The file will be automatically downloaded to your computer
2. Place the downloaded file in this folder (`public/decorations/`)
3. The decoration will immediately appear on the cork board

## Best Practices

- Use transparent PNG images for best results
- Keep file sizes reasonable (under 1MB recommended)
- Use descriptive filenames
- Commit decoration images to git so they're available after deployment

## File Naming

Uploaded files are automatically named with the pattern:
`decoration-[timestamp]-[original-filename].png`
